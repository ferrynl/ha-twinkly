# Studio design standard

Use neutral graphite surfaces, restrained gold for selection and existing semantic colors for true device states. Keep the actual LED previews colorful. No ornamental gradients, excessive shadows or oversized headings. Preserve the four existing routes, translated labels, control IDs and hardware API. Keep diagnostics off the control page. Use local CSS and native controls first: no runtime CDN or mandatory framework. Add PixiJS, Three.js or GSAP only after profiling a concrete need. This beta is a presentation-layer iteration, not a hardware rewrite.

Validate desktop and mobile navigation, focus visibility, horizontal overflow, device actions and all four languages. Hardware confirmation remains a separate manual gate.

## Product identity
Christmas Control Center is the user-facing brand. Preserve the existing addon slug and LedFX device identity to avoid breaking upgrades and music routing. Version 2.0 roadmap: Philips Hue integration; no Hue controls until supported.
