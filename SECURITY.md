# Security policy

Security fixes are delivered in the latest stable Christmas Control Center and the latest Home Assistant beta.

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/ferrynl/ha-twinkly/security/advisories/new). Include the affected version, the affected component and enough detail to verify the issue. Remove tokens, device credentials and private Home Assistant data from attachments.

Please keep reports private while the issue is being investigated and a fix is prepared.
